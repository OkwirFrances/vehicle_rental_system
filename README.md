# Vehicle Rental System

An application for managing a small vehicle rental business: add and search
vehicles (Car, Motorcycle, Van), register customers, rent and return vehicles with
a price summary and receipt, and view statistics. Data is stored in arrays.

## Run it
Requires JDK 11 or newer.

    cd src
    javac *.java
    java Main

(or open the `src` folder and run `Main`.)

## Files
| File | Purpose
| Main.java | Entry poin |
| RentalSystemGUI.java | Swing window: banner, four tabs, status bar |
| RentalManager.java | Arrays + business logic (rent, return, search, validation) |
| Vehicle.java, Car.java, Motorcycle.java, Van.java | Vehicle hierarchy (inheritance, polymorphism) |
| Customer.java, Rental.java | Other entities |
| RentalException.java | Custom exception |
